# FRC · FastRetailingCalendar

근무 일정 확인에 집중한 Android 앱입니다. 월간 캘린더와 홈 화면 위젯으로 근무시간·휴무·출장을 확인할 수 있습니다.

**Fast Retailing·UNIQLO가 제공하거나 승인한 공식 앱이 아닌 개인 개발 비공식 앱입니다.** 업무 계정과 WPS 이용 권한이 있는 사용자만 실제 일정을 연결할 수 있습니다. 계정을 연결하지 않아도 샘플 일정을 살펴볼 수 있습니다.

이 저장소는 **설치 파일과 릴리즈 안내만 공개하는 배포 전용 저장소**입니다. 앱 소스 코드는 포함하지 않습니다.

## 다운로드

[최신 Android APK 다운로드](https://github.com/gijang-jmj/frc-releases/releases/latest)

- 현재 버전: **0.14.1 (빌드 25)**
- 지원: Android 8.0 이상. iOS는 아직 제공하지 않습니다.
- 설치는 릴리즈에 첨부된 **`.apk`** 파일을 받으세요.
- GitHub가 표시하는 `Source code (zip/tar.gz)`에는 이 배포 저장소의 문서만 들어 있습니다. 앱 설치 파일이 아닙니다.

0.6.0 이하 정식판에서는 이번 APK를 직접 설치하세요. 0.7.0~0.9.0에서는 **설정 → 업데이트 확인**에서 새 버전을 받으세요. 0.10.0부터는 **설정 → 앱 업데이트**에서 새 버전을 받고 버전별 변경 내역도 볼 수 있습니다.

## 주요 기능

- 월간 근무표: 근무시간·휴무·출장, 인접 월 일정, 날짜별 상세 확인
- 업무 계정 연결과 기기 내 암호화 저장, 세션 복구 및 자동 로그인 관리
- 홈 화면 위젯 4종: 오늘의 근무(2×2), 오늘부터 나흘을 보여주는 다가오는 근무(4×1), 2주 근무표(4×2), 월간 근무표(4×5)
- 조회 월에서 시간이 지정된 근무를 개별 또는 전체 선택하여 기기 캘린더로 내보내기
- 내보내기 제목 기본·직접 입력과 근무 시간 추가 선택, 설명 설정, 지원 캘린더의 알림·색상, 실제 미리보기 및 신규/갱신 건수 확인
- 로그인 전 샘플 일정 탐색, 주간·월간 미리보기에서 내보낼 제목과 근무 시간 확인, 기기 전용 FRC 캘린더 만들기·삭제, 네이버 캘린더 가져오기 안내 제공
- 앱과 위젯에 적용되는 월요일·일요일 시작 설정, 라이트·다크·시스템 테마, 마지막으로 저장한 일정 오프라인 확인

2주 근무표는 위젯에 공간이 충분하면 출근과 퇴근을 함께 보여줍니다. 작은 크기에서는 출근 시각이나 근무 상태를 먼저 표시합니다. 4일·월간 근무표는 날짜와 시각을 같은 줄에 맞춰 비교할 수 있습니다. 위젯 크기는 런처의 배치 기준이며, 기기의 실제 크기에 맞춰 표시 정보가 조절됩니다.

## 설치와 업데이트

1. 최신 릴리즈에서 `frc-0.14.1-25.apk`를 내려받습니다.
2. 파일을 열고 Android가 요청하면 해당 브라우저 또는 파일 앱의 ‘이 출처 허용’을 켜서 설치합니다.
3. FRC를 열고 업무 계정을 연결하거나 샘플 일정을 확인합니다.

기존 **릴리즈 앱**은 같은 서명의 APK로 업데이트할 수 있습니다. 0.3.0에서 0.14.1로 업데이트할 때 앱을 먼저 삭제할 필요가 없습니다.

현재 개발판 **FRC DEV**와 정식판 **FRC**는 한 기기에 함께 설치할 수 있습니다. 두 앱의 계정과 일정 캐시는 각각 관리됩니다.

정식판의 앱 내 업데이트는 사용자가 다운로드한 파일의 크기·해시·패키지·서명을 확인한 뒤 Android 설치 확인 화면을 엽니다. 설치 출처 허용은 시스템 설정에서 선택합니다.

## 데이터와 권한

- FRC는 WPS의 일정 조회만 제공합니다. 근무 신청·변경·승인이나 업무 원본 데이터 수정 기능은 제공하지 않습니다.
- 로그인 정보와 일정 캐시는 기기에 암호화하여 보관합니다. 로그인 정보는 사용자가 연결하는 정상 회사 인증 절차에 사용됩니다. 인증 정책·재인증·추가 인증 요구를 우회하지 않습니다.
- 캘린더 접근 권한은 일정 내보내기에 사용됩니다. 내보내기는 선택한 외부 캘린더에 반영되며 WPS 원본에는 영향을 주지 않습니다.
- 외부 캘린더 계정의 동기화 설정에 따라 내보낸 일정이 해당 서비스에 업로드될 수 있습니다.
- 캘린더 내보내기는 자동 양방향 동기화가 아닙니다. 시간이 있는 대상 근무만 내보내며 휴무·출장 등은 제외됩니다.
- **0.3.1부터 화면 캡처 차단을 해제했습니다.** 로그인 화면과 비밀번호 표시 상태도 캡처됩니다. 비밀번호 기본 마스킹과 암호화 저장은 유지됩니다.

## 사용 시 참고

0.12.0부터 설정 하단의 **FRC · FastRetailingCalendar**를 7회 연속 누르면 **개발자 옵션 → 인증 진단 로그**가 나타납니다. TalkBack에서는 브랜드의 **개발자 옵션 활성화** 작업을 선택할 수 있습니다.

회사 인증 정책에 따라 재로그인이 필요할 수 있습니다. 오프라인 일정과 위젯은 마지막 저장 데이터를 표시하므로 동기화 시각을 확인하세요. 기기·배터리·런처 정책에 따라 갱신이 늦어질 수 있습니다.

Android Emulator와 Galaxy에서 기능을 검증해 왔으나 모든 기기·런처·장기 백그라운드 동작을 보장하지 않습니다. 버전별 검증 결과와 미검증 범위는 각 릴리즈 노트를 확인하세요.
